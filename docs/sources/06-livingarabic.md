# Source 06: Living Arabic Project, livingarabic.com (checked 2026-10-13)

- Site by Lughatuna LLC ("© 2020 … ALL RIGHTS RESERVED"); one-person project funded on Patreon.
- Dictionaries: Classical, Levantine AR-EN, Levantine AR-AR, Egyptian, Maghrebi (North African), Gulf, Iraqi,
  Sudanese, Yemeni. Search by root, word, English meaning or examples. Entries: root → word (with vowels) → English
  meaning → example sentences tagged by dialect ([E], [G], [I] …), with "Rate Translation". Meaning ids reach about
  741,000 across dictionaries. The Egyptian entries look like Hinds & Badawi (e.g. the حادي بادي rhyme).
- One search (بدي, viewed once in the browser at Yahya's request): Classical 31, Levantine AR-EN 427 (root-level
  matches), Levantine AR-AR 10, Egyptian 31, North African 8, Gulf 21, Iraqi 32, Sudanese 5, Yemeni 5.

## Access: closed to automated collection
- `robots.txt` blocks GPTBot, Google-Extended, CCBot and **ClaudeBot** from the whole site; no sitemap.
- Terms: access "through any automated … means" is prohibited; copying / reproducing the resources is prohibited.
- Search forms use Google reCAPTCHA.

## Verdict
Probably the richest expert-made multi-dialect lexicon we have seen (9 dictionaries, examples per dialect), but it
cannot be crawled: the owner explicitly opts out of AI crawlers and automated access, and the search sits behind a
CAPTCHA. Not collected. Options: (1) Yahya asks the owner for a data licence / export (contact form or Patreon);
(2) use it by hand as a reference when checking hard words; (3) look for the printed source dictionaries it is built
on (e.g. Hinds & Badawi for Egyptian) through other channels.
