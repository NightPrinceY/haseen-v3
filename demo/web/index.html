One question per varietyIs the word natural in MSA? Egyptian? any Gulf variety? Saudi? Levantine? Iraqi? Maghrebi? One pass answers all of them; the target you pick decides which answer counts. «حضرتك» is Egyptian, so a Gulf agent that says it is flagged.
The service registerFormal open-class words (الفاتورة، التحويل، يمكنك) are shared; MSA grammar markers (سوف، سنقوم، لن، الذي) and other varieties' words are not.
Small and offlineOne Arabic encoder, int8 ONNX, one pass per sentence on a CPU; this page runs it in your browser. Judged on held-out native speech (Saudi TV, Egyptian speech, news) and real LLM agent replies.
