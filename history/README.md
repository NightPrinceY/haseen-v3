# Earlier builds

HaSeen went through three builds in three days. This folder keeps the first two as they were, so every claim about
them can be checked. The shipped model is Build 3 (the rest of this repository).

| Folder | Build | Scope | What is inside |
|---|---|---|---|
| `build1/` | HaSeen 1 (12–13 Oct) | Egyptian, Gulf, MSA | guideline, data study and plan, results, the gold-building trail (`annotation/`), all 9 runs (`experiments/`), benchmark and lexicons (`data/`), the original report (`report.html`) |
| `build2/` | HaSeen 2 (13–14 Oct) | nine varieties | targets decision, plan, guideline, pre-registration with decision records, results, run summaries (`runs/`), the results and architecture pages |

Why Build 3 replaced them: Build 2 scored 0.932 on its own bench, which shares its style with the training corpus;
on the fresh human-speech test of Build 3 it scores 0.819, and Build 3 scores 0.869 (`../docs/RESULTS.md`).
